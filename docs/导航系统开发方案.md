# HomeBot 导航系统开发方案

> 基于 `docs/homebot_nav_design.md` 的渐进式实现计划  
> 创建日期：2026-04-16  
> 策略：纯软件先行 → 复用现有硬件 → 逐步叠加新硬件

---

## 总体策略

1. **先软件、后硬件**：路径规划、代价地图等纯算法模块先用模拟环境跑通。
2. **先复用、后采购**：复用现有摄像头和底盘编码器，延迟激光雷达的接入。
3. **先局部、后全局**：先做避障和局部规划（可独立工作），最后做全局 SLAM 和地图导航。

---

## 阶段 4：2D 激光雷达与 SLAM（约 2-3 周）

**目标**：接入 2D 激光雷达，实现全局定位和地图构建。

### 关键决策（已更新）

| 决策点 | 最终方案 | 理由 |
|--------|----------|------|
| SLAM 算法 | **BreezySLAM (RMHC_SLAM)** | 纯 Python/C 扩展，树莓派可运行，API 极简 |
| 激光雷达 | **LD06 (LDRobot)** | 已采购，4500Hz 采样，360° 扫描，Python 驱动已自研 |
| 漂移修正 | **AprilTag (tag36h11) 视觉融合** | 解决 BreezySLAM 长时漂移，实现 0.1m 精度和绑架恢复 |

### 核心算法逻辑

```
高频 SLAM 线程 (10Hz): BreezySLAM → 相对位姿 (x_rel, y_rel, theta_rel) + 协方差 P_slam
低频视觉线程 (2Hz): AprilTag PnP → 绝对位姿 (x_abs, y_abs, theta_abs) + 协方差 P_tag

融合策略：
  硬校正：confidence > 0.8 → Split CIF 融合 → 重置 SLAM 粒子群（消除漂移）
  软融合：未检测到标签 → 纯 BreezySLAM + 里程计一致性监测
  绑架恢复：连续 5 帧 SLAM 匹配失败但检测到标签 → 全局重定位
```

| 4.1 | 激光雷达驱动 | ✅ 已完成 | `navigation/hal/lidar_driver.py`，纯 Python pyserial 实现，含 CRC8 校验和 Mock 回退 |

| 风险 | 应对措施 |

| BreezySLAM 在 Windows 上编译困难 | 已实现 MockSLAM 回退，开发调试可在 Windows 进行，部署时树莓派源码安装 BreezySLAM |
