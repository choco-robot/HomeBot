# 问题记录

## 1. onnxruntime无法使用GPU加速

### 问题描述
在使用 `onnxruntime` 进行深度估计时，发现即使安装了 GPU 版本的 `onnxruntime-gpu`，推理仍然在 CPU 上进行，导致性能较差。但torch已经正确使用GPU。

### 修复方案（二选一）

#### 方案 A：临时修复（立即生效，当前终端有效）
在启动 DepthService 的 PowerShell 终端中，先执行：

```
$env:PATH = $env:PATH + ";E:\develop\HomeBot\homebot\venv\lib\site-packages\torch\lib"
```
然后再运行深度服务

#### 方案 B：永久修复（推荐）
把 PyTorch 的 lib 目录添加到系统环境变量 PATH 中：

1. 按 Win + R，输入 sysdm.cpl，回车
2. 切换到 "高级" → "环境变量"
3. 在下半部分 "系统变量" 中找到 Path，双击编辑
4. 点击 "新建"，添加这行：
   E:\develop\HomeBot\homebot\venv\lib\site-packages\torch\lib (请替换为你torch的实际路径)
5. 一路点 "确定" 保存
6. 重启你的终端/VS Code，使环境变量生效
