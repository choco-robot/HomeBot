# HomeBot 导航系统架构设计

## 1. 系统概述

### 1.1 设计目标
- 实现室内轻量级自主导航与避障
- 不依赖ROS，保持HomeBot纯Python架构
- 适配树莓派4B算力，低成本硬件方案

### 1.2 核心能力
| 能力 | 实现方式 |
|------|----------|
| 全局定位 | 2D激光雷达 + Cartographer SLAM |
| 局部避障 | 单目深度估计（悬空障碍物检测） |
| 路径规划 | A* / Dijkstra 算法 |
| 运动控制 | 底盘里程计 + 速度闭环 |

---

## 2. 传感器配置

### 2.1 2D激光雷达
- **安装位置**：机器人底部中心
- **离地高度**：20-30cm
- **作用**：
  - SLAM建图与全局定位
  - 检测地面层障碍物（桌腿、墙壁、家具底部）
  - 生成栅格地图供路径规划使用

### 2.2 单目深度相机
- **安装位置**：机器人前部上方
- **离地高度**：40-50cm
- **俯仰角度**：向下倾斜10-15°
- **作用**：
  - 检测悬空障碍物（桌面、椅子座位、柜台）
  - 弥补2D雷达在垂直空间的感知盲区
  - 提供障碍物高度信息用于决策

### 2.3 底盘里程计
- **来源**：舵机编码器、速度回读，保留IMU扩展接口（暂不使用）
- **作用**：提供高频位姿估计，补偿SLAM低更新率

## 3. 软件架构

### 3.1 分层设计

```
┌─────────────────────────────────────────┐
│           应用层 (Applications)           │
│    导航任务管理 / 多点巡航 / 跟随模式       │
├─────────────────────────────────────────┤
│           规划层 (Planning)              │
│    全局路径规划(A*) / 局部路径规划(DWA)    │
├─────────────────────────────────────────┤
│           感知层 (Perception)            │
│  ┌─────────────┐    ┌─────────────┐    │
│  │  LidarService│    │ DepthService│    │
│  │  (Cartographer)│   │ (MiDaS/DepthAnything)│
│  └──────┬──────┘    └──────┬──────┘    │
│         └────────┬─────────┘            │
│            FusionService                │
│         (统一代价地图生成)                 │
├─────────────────────────────────────────┤
│           执行层 (Execution)             │
│    底盘控制服务 (ChassisService)          │
│    机械臂控制服务 (ArmService)            │
├─────────────────────────────────────────┤
│           硬件层 (HAL)                   │
│    激光雷达驱动 / 相机驱动 / 底盘驱动       │
└─────────────────────────────────────────┘
```

### 3.2 通信架构
- **总线**：ZeroMQ
- **消息格式**：JSON
- **关键Topic**：
  - `/slam/pose` - 机器人位姿
  - `/odom/pose` - 里程计位姿
  - `/slam/map` - 栅格地图
  - `/depth/obstacles` - 视觉障碍物
  - `/fusion/costmap` - 融合代价地图
  - `/cmd_vel` - 速度指令

## 4. 核心模块说明

### 4.1 Cartographer SLAM
- **定位**：核心C++库，剥离ROS依赖
- **输入**：2D激光扫描数据+底盘里程计数据
- **输出**：
  - 机器人实时位姿（x, y, yaw）
  - 占用栅格地图（Occupancy Grid Map）
  - 子地图与子图约束
- **集成方式**：Python pybind11绑定或独立进程通过ZeroMQ通信

### 4.2 单目深度估计
- **模型选择**：MiDaS-small 或 Depth Anything V2（轻量版）
- **运行环境**：树莓派CPU（~50ms/帧）
- **后处理**：
  - 逆深度转绝对深度
  - 点云生成与投影
  - 障碍物聚类与高度估计
- **输出**：3D障碍物列表（x, y, z, width, height）

### 4.3 多传感器融合
**融合策略**：
1. **雷达数据**：致命障碍物（cost=255），地面层
2. **视觉数据**：动态障碍物（cost=50-200），垂直空间
3. **时序滤波**：障碍物需连续多帧确认才生效
4. **冲突仲裁**：雷达与视觉冲突时，取最大代价值

**输出**：统一代价地图（Cost Map），供路径规划使用

## 5. 避障策略

### 5.1 分层避障

| 层级 | 传感器 | 响应方式 |
|------|--------|----------|
| L1 紧急避障 | 超声波/TOF（可选） | 立即制动 |
| L2 动态避障 | 单目深度相机 | 减速/绕行 |
| L3 全局避障 | 2D激光雷达 | 路径重规划 |

### 5.2 悬空障碍物处理
**场景**：机器人从两张桌子中间穿过

```
[桌子A]              [桌子B]
   │                    │
   └────┐          ┌────┘
        │  机器人  │
        │ [雷达]───┼──→ 雷达只扫描到地面，认为路径畅通
        │          │
        │ [相机]───┼──→ 相机检测到桌面，发现悬空障碍
        └──────────┘
```

**决策逻辑**：
1. 检测障碍物高度
2. 若高度 > 机器人高度：从下方安全穿越
3. 若高度 < 机器人高度：标记为障碍，触发绕行

## 8. 风险提示

1. **算力瓶颈**：深度估计模型较大，可能需要量化或降采样
2. **标定依赖**：相机-雷达外参标定直接影响融合精度
3. **光照敏感**：单目深度在弱光环境下性能下降
4. **ROS-free限制**：Cartographer剥离ROS需要较多工程工作
