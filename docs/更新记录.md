## 2026-09-06 - LeRobot 插件封装包与接入文档

### 新增功能

- **LeRobot 第三方插件封装包**（`plugins/lerobot_robot_homebot/`）
  - 包名遵循官方插件发现约定（`lerobot_robot_` 前缀，要求 lerobot≥0.4.0）
  - 在 venv-lerobot 中 `pip install -e ./plugins/lerobot_robot_homebot` 后，`lerobot.record --robot.type=homebot` 等官方 CLI 自动发现 HomeBot，无需手动 import
  - 封装包置于 `plugins/` 子目录而非仓库根目录，避免根目录同名外层目录被当作命名空间包遮蔽已安装插件

- **接入文档**（`docs/LeRobot 生态接入.md`）
  - Robot 适配器注册机制（register_subclass / 命名约定实例化 / 插件自动发现）
  - 环境准备、数据采集与校准约定
  - 推理部署：自研 policy_runner 服务级链路 vs 官方 async inference 的取舍

### 其他

- `requirements-lerobot.txt` 的 lerobot 下限提升至 >=0.4.0（插件发现机制自该版本起提供），新增 pyzmq 依赖（policy_runner 经 ZMQ 服务通道取图与下发动作）
- `tests/test_imitation_learning.py` 新增插件封装包导入测试

### Bug 修复（lerobot 0.5.1 端到端验证中发现）

- 修复 `robot.py` 导入：`RobotAction` / `RobotObservation` 类型别名在 lerobot 0.5.1 位于 `lerobot.types`（原 `lerobot.lerobot_types` 不存在）
- 修复 `policy_runner.py` 导入：`PreTrainedConfig` 位于 `lerobot.configs.policies`（原 `lerobot.configs` 不再导出）
- `applications/imitation_learning/__init__.py` 补充导出 `HomeBotRobot` / `HomeBotRobotConfig`：lerobot 0.5.x 的设备类查找候选不含配置类自身模块，需在父包暴露设备类

### 验证结果

在 lerobot 0.5.1 环境（`E:\develop\lerobot-v0.5.1-custom`）完成无硬件端到端验证：
插件自动发现 → `--robot.type=homebot` CLI 参数解析 → `make_robot_from_config` 实例化 →
observation/action features 输出正确（6 关节 + omni3 底盘速度键），真机数采/推理待硬件验证。

## 2026-08-24 - LeRobot 集成（feature/lerobot 分支）

将 HomeBot 接入 LeRobot 生态，支持 ACT / SmolVLA 等模型的数据采集与推理部署。

### 新增功能

- **LeRobot Robot 适配器**（`applications/imitation_learning/robot.py`）
  - `HomeBotRobot` 实现 LeRobot 官方 `Robot` 接口，注册为 `type="homebot"`
  - 数采/遥操作直接复用官方工具链：`lerobot.record` + 原生 `so101_leader` 主臂
  - 机械臂采用 LeRobot 标准校准与关节命名（shoulder_pan/lift、elbow_flex、wrist_flex/roll、gripper），数据集与官方生态互通
  - 校准约定：校准时机械臂摆放在 HomeBot 零位姿态，两套坐标系重合，现有控制功能不受影响

- **底盘双形态适配**（`chassis_adapter.py`）
  - `omni3` 三轮全向：轮舵机注册到 lerobot 电机总线（共享串口），速度键沿用 LeKiwi 约定（`x.vel/y.vel/theta.vel`）
  - `diff2` 双轮差动：懒加载 homebot-navi 分支的 `diff_driver`，分支合并后即用；横向速度自动忽略并告警
  - `none` 纯机械臂模式

- **策略推理部署**（`policy_runner.py`）
  - 服务级运行：图像走 vision_service（5560），关节经 arm_service（5557）查询，动作经仲裁器下发（`source="auto"`，保留急停与超时保护）
  - 支持跨机器部署（策略在 GPU 机器推理，机器人在远端）
  - `--dry-run` 模式验证链路不下发动作

- **校准验证工具**（`verify_calibration.py`）：对比 LeRobot 与 HomeBot 两侧关节读数

### 其他

- 删除损坏的占位 stub `imitation.py`
- 新增 `requirements-lerobot.txt`（独立环境安装，不进主 venv）
- 新增 `tests/test_imitation_learning.py`（关节映射、运动学正逆解、底盘工厂）

## 2026-08-24 - 通用消息总线与 homebot CLI

本次更新增加通用的发布/订阅消息接口，并新增统一的命令行工具 `homebot`。

### 新增功能

- **通用消息总线（Message Bus）**
  - 新增 `services/message_bus/` 服务：XPUB-XSUB 代理（XSUB bind 5590 / XPUB bind 5591），发布者与订阅者均 connect 到 broker，新增消息通道无需申请端口
  - 新增 `common/bus.py` 客户端封装：`BusPublisher` / `BusSubscriber`（topic 前缀订阅 + 后台线程回调分发）、`ZMQRequestClient`（超时自动重建 socket 的通用 REQ 客户端）
  - `common/messages.py` 开放消息类型：`serialize()` 支持任意字符串类型，用户自定义消息约定使用 `user.*` / `ext.*` 前缀
  - `configs/config.py` 的 `ZMQConfig` 新增 `bus_xsub_addr` / `bus_xpub_addr`
  - `start_system.py` 注册 Message Bus 服务

- **homebot CLI 工具**（`software/src/homebot_cli/`）
  - 统一入口替代 `python -m`：editable 安装后直接使用 `homebot` 命令
  - 服务管理：`homebot start/stop/restart/status/logs`（后台运行，日志写入 `software/logs/`，PID 文件在 `software/cache/run/`）
  - 调试命令：`homebot topic echo/pub`（类似 ros topic echo/pub）、`homebot move`（底盘速度命令，到时自动停止）
  - 环境检查：`homebot doctor`（Python/配置/密钥/串口/模型/端口）
  - Tab 补全：基于 click 内置实现，支持 bash/zsh/fish（Windows 下推荐 Git Bash），`homebot completion` 查看激活方法
  - 新增打包脚本 `tools/build_homebot_cli_exe.py`，可打包为单文件 `dist/homebot.exe` 作为控制端/调试端工具（打包版不含服务管理命令）

### Bug 修复

- 修复 `common/logging.py` 的循环导入问题（`configs.config → configs.secrets → common.logging`），该问题导致 logger 级别错误回退为 DEBUG，CLI 输出与 tab 补全被日志噪音污染；日志级别现统一由环境变量 `HOMEBOT_LOG_LEVEL` 控制，默认 INFO
- 修复 `homebot start` 在 Windows 上弹出空控制台窗口的问题：Python 3.13 的 venv 重定向器会再拉起 base 解释器孙进程，`DETACHED_PROCESS` 下孙进程会新建可见窗口，改为 `CREATE_NO_WINDOW` 后孙进程继承隐藏控制台

### 新增测试

- `tests/test_message_bus.py`：消息总线发布/订阅往返、topic 前缀过滤、消息类型兼容
- `tests/test_homebot_cli.py`：CLI 命令解析、status/doctor 输出、topic pub/echo 往返

## 2026-04-28 - Choco-Arm 硬件与视觉增强

**Choco-Arm** 是 HomeBot 在机械臂硬件建模、视觉感知和语音交互方面的重大更新，合并自 `choco-arm` 分支。

### 新增功能

- **SO-101 机械臂 URDF 模型与精确运动学**
  - 新增完整的 SO-101 机械臂 URDF 模型文件（含新旧校准版本、Plus 版本）
  - 提供全套 3D 打印零件 STL 文件（底座、电机支架、上下臂、腕部、夹爪等）
  - 重构 `Kinematics.py`，新增 `Arm3DKinematics` 类，基于 **ikpy** 库实现 5DOF 精确逆运动学计算
  - 支持通过 URDF 模型自动提取关节链，替代传统几何法运动学
  - `requirements.txt` 新增 `ikpy>=3.4.2` 依赖

- **AtomS3R-M12 网络摄像头模块支持**
  - 新增 `WebCamera` 驱动类（`hal/camera/webcamera_driver.py`），支持 AtomS3R-M12 等网络摄像头
  - 视觉服务（`vision_service`）增加网络摄像头连接支持，可自动切换本地/USB 摄像头与网络摄像头
  - 支持通过 HTTP 流（MJPEG）读取图像，兼容 ESP32-CAM、AtomS3R-M12 等模组
  - 新增 `test_vision_detector.py` 测试脚本，用于验证视觉检测与摄像头集成

- **机械臂人脸跟踪功能**
  - 新增 `face_tracking` 应用模块，实现机械臂自动人脸跟踪
  - 基于 YOLOv8 人脸检测模型（`yolov8n-face-lindevs`），支持实时人脸检测与跟踪
  - 机械臂通过视觉伺服控制，自动调整姿态使目标人脸保持在画面中心
  - 支持通过语音交互系统调用（MCP 工具集成）
  - 启动方式：`python -m applications.face_tracking`

- **语音交互 MCP 工具增强**
  - `mcp_server.py` 新增人脸跟踪相关 MCP 工具（模型预加载、状态查询、启停控制）
  - `dialogue_manager.py` 优化对话上下文管理与工具调用逻辑
  - `speech_app.py` 改进语音应用与 MCP 服务器的交互流程
  - 新增 `yolov8n-face-lindevs` 模型自动下载支持（`download_models.py`）

- **新增硬件结构零件**
  - 双轮底座（`dualwheelbase`）系列：盖板、无刷电机支架（v1/v2）STL/3MF 文件
  - Kiwi 底座（`kiwi_base`）系列：底板、连接件 STL/3MF 文件

### 配置更新

- `config.py` 新增人脸跟踪、网络摄像头相关配置项
- `secrets.py` 优化密钥管理，改进环境变量读取逻辑
- `.env.example` 更新环境变量模板，新增视觉与语音相关配置项

## 2025-03-28 - HomeBot Plus 版本发布

**HomeBot Plus** 是 HomeBot 的硬件增强版本，新增**升降平台（Lift Platform）**功能，支持机械臂整体高度调节。

### 新增功能

- **升降平台控制**
  - 双舵机同步驱动，丝杆传动结构
  - 行程范围：0 ~ -200mm（0 为最高点）
  - 支持自动零点找零（电流检测限位）
  - 网页端和手柄均可控制升降
  
- **网页端升级**
  - 新增升降平台控制按钮（上升/下降）
  - 实时显示当前高度
  - 支持一键归位（机械臂 + 升降平台同时复位）
  
- **游戏手柄升级**
  - 十字键上下：控制升降平台移动
  - 新增升降高度显示
  
- **硬件配置**
  ```python
  @dataclass
  class LiftPlatformConfig:
      servo_id_1: int = 10        # 升降舵机1 ID
      servo_id_2: int = 11        # 升降舵机2 ID
      stroke_length: float = 200.0   # 行程长度 (mm)
      lead: float = 2.0              # 丝杆导程 (mm/转)
      gear_ratio: float = 2.0        # 减速比
  ```

- **新增工具脚本**
  - `test_lift_platform.py` - 升降平台基础测试
  - `test_lift_homing.py` - 零点找零测试
  - `verify_lift_integration.py` - 集成验证

### 注意事项

- HomeBot Plus 需要额外的 2 个舵机驱动升降平台
- 升降平台使用步进模式（Mode=3）控制
- 首次使用需执行零点找零校准

### 分支说明

- `main` - 标准版 HomeBot（无升降平台）
- `homebot-plus` - 增强版 HomeBot（带升降平台）

### Bug 修复

- 修复了 Kinematics.py 中关于手腕关节角度计算的 bug
- calibrate_arm 工具启动时会自动释放所有关节扭矩

## 2025-03-24 - 语音交互与视觉理解

### 新增功能

- **新增语音交互系统**，基于本地语音识别 + 云端大模型 + 语音合成，实现自然语言控制机器人
  - **语音唤醒与识别**：本地部署 sherpa-onnx 唤醒词检测 + 流式 ASR，支持自定义唤醒词（如"你好小白"）
  - **大模型对话**：集成 `Doubao-seed-2.0-mini` API，支持多轮对话和工具调用
  - **MCP 工具集成**：语音可调用底盘运动、机械臂控制、视觉理解等工具
  - **语音合成**：集成火山引擎 TTS，支持 Seed-TTS 2.0 高质量音色
  - **一键启动**：`python start_speech_service.py` 自动启动 Wakeup+ASR 服务和语音交互应用
  - 详见 [语音交互使用指南](语音交互使用指南.md) 和 [自定义唤醒词配置指南](自定义唤醒词配置指南.md)

- **新增视觉理解功能**，机器人可"看到并理解"眼前画面
  - 订阅 VisionService 获取最新图像帧
  - 调用 `Doubao-seed-2.0-mini` 模型分析画面内容
  - 可被语音应用通过 MCP 调用，回答"你看到了什么"等问题
  - 独立运行：`python -m applications.vision_understanding`

- **新增安全的 API 密钥管理机制**，支持从环境变量或 `.env.local` 文件加载敏感配置
  - 详见 [API 密钥配置指南](API密钥配置指南.md)

- **重构运动学模块**，将 `ArmKinematics` 类整合至 `/hal/arm/Kinematics.py`，统一网页遥控端和语音交互端的运动学计算

- **新增电池状态监测功能**，通过舵机总线读取电源电压
  - HAL 层新增 `BatteryDriver`，支持电压/温度读取、电量百分比计算
  - 底盘服务集成电池状态发布（ZeroMQ PUB）
  - 新增消息类型 `sensor.battery`，包含电压、电量、状态、温度等字段
  - 支持低电量警告和电压阈值配置
