## 2026-07-09 - LLM 配置与机械臂 WLAN 遥操作

本次更新聚焦 LLM 配置灵活性、TTS 诊断能力和机械臂 WLAN 遥操作功能。

### 新增功能

- **LLM 提供商可配置**
  - 支持通过 `.env.local` 中的 `LLM_PROVIDER` 切换 `volcano`（火山 Ark）/`deepseek`/`qwen`（通义千问）
  - `configs/secrets.py` 根据 provider 自动读取对应环境变量并设置默认 URL 和模型
  - `configs/config.py` 同步 provider，便于应用层统一访问

- **机械臂 WLAN 遥操作应用**
  - 新增 `applications/arm_teleop/` 模块
  - 主臂读取（本地 SO101）+ 从臂客户端（ZeroMQ REQ-REP）
  - 支持关节映射/限幅/死区、速度自适应、通信失败保护
  - 支持录制/回放轨迹、速度缩放、循环播放
  - 提供键盘热键控制和 tkinter GUI
  - 新增 PyInstaller 打包脚本 `tools/build_arm_teleop_exe.py`

### 新增测试与工具

- `tests/test_llm.py`：LLM 连接诊断脚本
- `tests/test_arm_teleop.py`：遥操作功能测试
- `tools/build_arm_teleop_exe.py`：打包遥操作 GUI 为独立 exe

### 配置更新

- `.env.example` 增加 `LLM_PROVIDER` 说明，细化火山 Ark / DeepSeek 配置注释

### 模块变更

| 模块 | 变更类型 | 说明 |
|------|----------|------|
| `configs/secrets.py` | 增强 | 按 provider 读取 LLM 环境变量 |
| `configs/config.py` | 增强 | 同步 provider，支持 qwen 默认配置 |
| `services/speech_service/tts_client.py` | 增强 | HTTP 403 诊断日志 |
| `applications/arm_teleop/` | 新增 | 机械臂 WLAN 遥操作 |
| `tests/test_llm.py` | 新增 | LLM 连接诊断 |
| `tests/test_arm_teleop.py` | 新增 | 遥操作测试 |
| `tools/build_arm_teleop_exe.py` | 新增 | GUI 打包脚本 |

## 2026-04-28 - Choco-Arm 硬件与视觉增强

**Choco-Arm** 是 HomeBot 在机械臂硬件建模、视觉感知和语音交互方面的重大更新，合并自 `choco-arm` 分支。

### 新增功能

- **SO-101 机械臂 URDF 模型与精确运动学**
  - 新增完整的 SO-101 机械臂 URDF 模型文件（含新旧校准版本、Plus 版本）
  - 提供全套 3D 打印零件 STL 文件（底座、电机支架、上下臂、腕部、夹爪等）
  - 重构 `Kinematics.py`，新增 `Arm3DKinematics` 类，基于 **ikpy** 库实现 5DOF 精确逆运动学计算
  - 支持通过 URDF 模型自动提取关节链，替代传统几何法运动学
  - `requirements.txt` 新增 `ikpy>=3.4.2` 依赖

- **AtomS3R-M12 网络摄像头模块支持**
  - 新增 `WebCamera` 驱动类（`hal/camera/webcamera_driver.py`），支持 AtomS3R-M12 等网络摄像头
  - 视觉服务（`vision_service`）增加网络摄像头连接支持，可自动切换本地/USB 摄像头与网络摄像头
  - 支持通过 HTTP 流（MJPEG）读取图像，兼容 ESP32-CAM、AtomS3R-M12 等模组
  - 新增 `test_vision_detector.py` 测试脚本，用于验证视觉检测与摄像头集成

- **机械臂人脸跟踪功能**
  - 新增 `face_tracking` 应用模块，实现机械臂自动人脸跟踪
  - 基于 YOLOv8 人脸检测模型（`yolov8n-face-lindevs`），支持实时人脸检测与跟踪
  - 机械臂通过视觉伺服控制，自动调整姿态使目标人脸保持在画面中心
  - 支持通过语音交互系统调用（MCP 工具集成）
  - 启动方式：`python -m applications.face_tracking`

- **语音交互 MCP 工具增强**
  - `mcp_server.py` 新增人脸跟踪相关 MCP 工具（模型预加载、状态查询、启停控制）
  - `dialogue_manager.py` 优化对话上下文管理与工具调用逻辑
  - `speech_app.py` 改进语音应用与 MCP 服务器的交互流程
  - 新增 `yolov8n-face-lindevs` 模型自动下载支持（`download_models.py`）

- **新增硬件结构零件**
  - 双轮底座（`dualwheelbase`）系列：盖板、无刷电机支架（v1/v2）STL/3MF 文件
  - Kiwi 底座（`kiwi_base`）系列：底板、连接件 STL/3MF 文件

### 配置更新

- `config.py` 新增人脸跟踪、网络摄像头相关配置项
- `secrets.py` 优化密钥管理，改进环境变量读取逻辑
- `.env.example` 更新环境变量模板，新增视觉与语音相关配置项

### 模块变更

| 模块 | 变更类型 | 说明 |
|------|----------|------|
| `hal/arm/Kinematics.py` | 重大重构 | 新增 ikpy -based 3D 运动学 |
| `hal/camera/webcamera_driver.py` | 新增 | AtomS3R-M12 网络摄像头驱动 |
| `applications/face_tracking/` | 新增 | 机械臂人脸跟踪应用 |
| `services/vision_service/` | 增强 | 支持网络摄像头切换 |
| `applications/speech_interaction/` | 增强 | MCP 工具、对话管理优化 |
| `hardware/structure/URDF/SO101/` | 新增 | 机械臂 URDF 与 STL 零件 |
| `hardware/structure/STL/` | 新增 | 双轮/Kiwi 底座零件 |

## 2025-03-28 - HomeBot Plus 版本发布

**HomeBot Plus** 是 HomeBot 的硬件增强版本，新增**升降平台（Lift Platform）**功能，支持机械臂整体高度调节。

### 新增功能

- **升降平台控制**
  - 双舵机同步驱动，丝杆传动结构
  - 行程范围：0 ~ -200mm（0 为最高点）
  - 支持自动零点找零（电流检测限位）
  - 网页端和手柄均可控制升降
  
- **网页端升级**
  - 新增升降平台控制按钮（上升/下降）
  - 实时显示当前高度
  - 支持一键归位（机械臂 + 升降平台同时复位）
  
- **游戏手柄升级**
  - 十字键上下：控制升降平台移动
  - 新增升降高度显示
  
- **硬件配置**
  ```python
  @dataclass
  class LiftPlatformConfig:
      servo_id_1: int = 10        # 升降舵机1 ID
      servo_id_2: int = 11        # 升降舵机2 ID
      stroke_length: float = 200.0   # 行程长度 (mm)
      lead: float = 2.0              # 丝杆导程 (mm/转)
      gear_ratio: float = 2.0        # 减速比
  ```

- **新增工具脚本**
  - `test_lift_platform.py` - 升降平台基础测试
  - `test_lift_homing.py` - 零点找零测试
  - `verify_lift_integration.py` - 集成验证

### 注意事项

- HomeBot Plus 需要额外的 2 个舵机驱动升降平台
- 升降平台使用步进模式（Mode=3）控制
- 首次使用需执行零点找零校准

### 分支说明

- `main` - 标准版 HomeBot（无升降平台）
- `homebot-plus` - 增强版 HomeBot（带升降平台）

### Bug 修复

- 修复了 Kinematics.py 中关于手腕关节角度计算的 bug
- calibrate_arm 工具启动时会自动释放所有关节扭矩

## 2025-03-24 - 语音交互与视觉理解

### 新增功能

- **新增语音交互系统**，基于本地语音识别 + 云端大模型 + 语音合成，实现自然语言控制机器人
  - **语音唤醒与识别**：本地部署 sherpa-onnx 唤醒词检测 + 流式 ASR，支持自定义唤醒词（如"你好小白"）
  - **大模型对话**：集成 `Doubao-seed-2.0-mini` API，支持多轮对话和工具调用
  - **MCP 工具集成**：语音可调用底盘运动、机械臂控制、视觉理解等工具
  - **语音合成**：集成火山引擎 TTS，支持 Seed-TTS 2.0 高质量音色
  - **一键启动**：`python start_speech_service.py` 自动启动 Wakeup+ASR 服务和语音交互应用
  - 详见 [语音交互使用指南](语音交互使用指南.md) 和 [自定义唤醒词配置指南](自定义唤醒词配置指南.md)

- **新增视觉理解功能**，机器人可"看到并理解"眼前画面
  - 订阅 VisionService 获取最新图像帧
  - 调用 `Doubao-seed-2.0-mini` 模型分析画面内容
  - 可被语音应用通过 MCP 调用，回答"你看到了什么"等问题
  - 独立运行：`python -m applications.vision_understanding`

- **新增安全的 API 密钥管理机制**，支持从环境变量或 `.env.local` 文件加载敏感配置
  - 详见 [API 密钥配置指南](API密钥配置指南.md)

- **重构运动学模块**，将 `ArmKinematics` 类整合至 `/hal/arm/Kinematics.py`，统一网页遥控端和语音交互端的运动学计算

- **新增电池状态监测功能**，通过舵机总线读取电源电压
  - HAL 层新增 `BatteryDriver`，支持电压/温度读取、电量百分比计算
  - 底盘服务集成电池状态发布（ZeroMQ PUB）
  - 新增消息类型 `sensor.battery`，包含电压、电量、状态、温度等字段
  - 支持低电量警告和电压阈值配置
